# Mini Projects

A collection of beginner-friendly web development projects covering pure HTML/CSS/JavaScript, React, and full-stack Express applications.

## Projects

| Project | Description | Stack |
|---|---|---|
| [Amazon_Clone](./Amazon_Clone) | Static Amazon-inspired storefront layout | HTML, CSS |
| [Basic_Calculator](./Basic_Calculator) | Browser calculator with arithmetic operations | HTML, CSS, JavaScript |
| [Portfolio](./Portfolio) | Personal portfolio built with React and Vite | React, Tailwind CSS, Framer Motion |
| [StayHub](./StayHub/MAJORPROJECT) | Accommodation listing application with authentication and CRUD features | Node.js, Express, MongoDB, EJS |
| [Tic_Tak_Toe](./Tic_Tak_Toe) | Two-player tic-tac-toe game | HTML, CSS, JavaScript |
| [Vocabulary_Builder](./Vocabulary_Builder/Portfolio1) | React-based vocabulary learning project | React, Vite |

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Frameworks:** React 19, Vite 6
- **Styling:** Tailwind CSS, CSS
- **Animation:** Framer Motion
- **Backend:** Node.js, Express
- **Database:** MongoDB with Mongoose
- **Templates:** EJS
- **Authentication:** Passport
- **Image hosting:** Cloudinary
